# 伴学萌宠完整穿戴素材

2026-11-04：用按物种和成长阶段绘制的完整穿戴图替代配饰定位叠层，解决不同体型下装扮错位的问题。

## 素材范围

六宠：`moss` 苔苔、`ember` 焰尾、`ink` 墨羽、`thunder` 霆霆、`otter` 沫沫、`dream` 眠眠。

四阶段：`s0`、`s1`、`s2`、`s3`。阶段按现有 `stageOf(level)` 选择，与成长规则保持一致。

八款：`noodle` 泡面头、`melon` 西瓜盔、`doge` 狗头面具、`shades` 大佬墨镜、`fish` 咸鱼披风、`drumstick` 鸡腿权杖、`helmet` 鱼缸头盔、`dino` 恐龙睡衣。

共 192 个组合，每个组合提供两档 WebP：

```text
raw-assets/skins/{skin}-worn-{pet}-s{stage}.png
src/assets/skins/{skin}-worn-{pet}-s{stage}-128.webp
src/assets/skins/{skin}-worn-{pet}-s{stage}-256.webp
```

PNG 为透明原图，网页使用保留透明通道的 WebP。旧的独立配饰和不分阶段素材保留，避免破坏历史资源；当前完整穿戴图优先级最高。

按用户要求，网页与交付包提供 128/256 像素的轻量 WebP。原始 PNG 留在本地素材目录。

## 渲染约定

- `wornSources(skinId, petId, stage)` 必须匹配当前阶段。仅 `s0` 兼容旧的不分阶段命名。
- `PetAvatar` 显示一张完整穿戴图，不再叠加独立配饰或 CSS 装扮。
- 当前阶段缺图时显示该阶段的基础宠物，不能用幼体穿戴图代替成长后的体型。
- 商店预览、列表头像和详情头像共用 `PetAvatar`，升级后自动切换对应成图。
- 装扮 ID、徽章价格、已购记录和装备字段保持原有含义，不需要迁移学生数据。

## 生成与复核

使用内置 ImageGen，逐张以对应阶段的基础宠物为参考生成。提示词要求保持物种、成长轮廓、肢体数量和绘本质感，配饰服从角色的头部朝向与身体结构。狗头改为夸张柴犬布偶面具，含挑眉、侧目和歪嘴笑。

素材交付包附有逐张提示词和六张全阶段预览。复核需覆盖 192 个组合的透明通道、尺寸、两档资源以及实际浏览器加载，尤其留意长角、羽翼和尾部是否保留、配饰是否贴合。
